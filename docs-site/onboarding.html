Onboarding Data

What every user must fill in, step by step, and where each value is saved. Employees get an account from the Admin; suppliers register themselves.

Rule: an employee cannot open any dashboard until BOTH the fingerprint and the face are registered. The server checks BiometricCredentials AND FaceEnrollments, not just a flag on the page.
Rule: suppliers are users too, so fingerprint AND face are required for them as well. They register the company first, the Admin approves it, and on the first login the supplier completes the same biometric steps as an employee (steps 5 to 7).
