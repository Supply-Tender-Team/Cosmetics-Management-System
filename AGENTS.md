# Instructions for AI assistants

Before doing ANY work in this repository, read **`AI_INSTRUCTIONS.md`** (repo root) completely and follow it strictly.

The short version:
- Only edit the files of your own task/area. Never touch another developer's code or any shared file.
- Keep it simple: plain controllers, ViewModels, entities. No advanced patterns or new framework-like classes.
- Never commit `.env`, `bin/`, `obj/`, `.vs/`, `*.user`, uploads or secrets.
- If a task needs a change in a shared file, stop and ask the user.
