# Evaluation report handoff to Deyaa: Evaluation tracking

This supersedes the earlier Offer ranking component integration plan. Nada should keep her existing short Offer ranking table. No component call or report button is requested there.

When all four assigned members confirm Ready for EVERY eligible bid, Evaluation saves one EvaluationReport with TenderId, TechnicalSummary, FinancialSummary, Justification, PreparedByUserId, CreatedAt, SubmittedAt, and Recommendation Pending status. Drafts and saved scores do not trigger delivery. It sets the active tender to Under Evaluation; it does NOT set Awaiting Manager Review or notify the Manager. No winner is selected automatically.

EvaluationReportReady goes to the tender creator (Sourcing Officer). The link generated by AssessmentsController is Sourcing/Evaluation/Index with query tenderId, e.g. /Sourcing/Evaluation?tenderId=22 (routing may include /Index). Existing report notifications in the local test DB are updated separately. No Sourcing/shared source file is changed.

The current Sourcing EvaluationController.Index already reads EvaluationReports by TenderId, exposes LatestReport including both summaries, and shows the full report on its existing tracking page. Its CanSendReportToManager checks a saved report, SubmittedAt, Recommendation Pending, Under Evaluation status, and an assigned SourcingManager. Its SendToManager action belongs to Deyaa. Marwa does not invoke or change that action.

Deyaa owns progress-card labels and Manager forwarding. Some current progress indicators count saved scores rather than all ReadyAt confirmations; the presence of our submitted report is the reliable completed-committee handoff. If Deyaa changes those labels or adds structured display, she owns those page changes. The EvaluationResultsReport component is ready for Deyaa to embed in the tracking report modal to match the committee design; see TRACKING-REPORT-DISPLAY-FOR-DEYAA.md. Automatic receipt of the database report itself needs no component.

No database migration or package change is required. The committee's own readable report remains available inside Evaluation.
